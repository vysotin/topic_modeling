# Topic Modeling and Topic Sentiment analysis

My goal was to create end-to-end solution for extracting topics from the large corpus of texts that also have a 
date attribute, like news, scientific articles, etc. 
The notebook also offer evolution analysis of topics in given corpus and explore the ways to extract the topic related sentiment for given text.
The implementation is presented in python notebook topic_modeling.ipynb. HTML image of this this notebook with calculated outputs is provided topic_modeling.htm

## Setup and running

Environment is python 3.7 with dependencies listed in requirements.txt for pip installation 
(pip install -r requirements.txt) and environment.yml for conda runs (conda env create -f environment.yml).

To start notebook in given environment run the command: 
```
jupiter notebook topic_modeling.ipynb
```
